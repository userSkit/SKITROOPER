# SKITROOPER — €10 → €10,000 in received cash

One operator (Ireland), one computer, €10 starting capital. Money in the bank is the only metric.

## How this repo works

| File | What it is | Who writes it |
|---|---|---|
| `INTAKE.md` | Questions you must answer before stage 1 is locked | You |
| `ledger.csv` | Every euro in/out. **Nothing counts until you confirm it** (`confirmed` column = `yes`) | Claude drafts, you confirm |
| `decision_log.md` | Every pivot, kill, or double-down, with the reason | Claude |
| `research/stage1.md` | Opportunity research + tournament for the €10 → €100 stage | Claude |
| `offers/` | Copy-paste listing text, outreach messages, reply templates | Claude |
| `logs/outreach_log.csv` | Every message sent, every reply, every conversion | You report, Claude records |
| `logs/reviews/` | 3-day reviews and weekly one-page recaps | Claude |
| `system/` | The written, repeatable system for whatever business gets us there | Claude |

## Stage gates

| Stage | Target banked | Status |
|---|---|---|
| 1 | €100 | Not started — waiting on `INTAKE.md` |
| 2 | €1,000 | Locked |
| 3 | €5,000 | Locked |
| 4 | €10,000 | Locked |

A stage advances only when `ledger.csv` shows the target as confirmed, received cash.

## Human-only actions (Claude never does these)
Payments, purchases, ad spend, account creation, logins, sending any message or post, accepting terms, anything touching your tax/legal/personal data. Claude prepares each of these as a one-click decision for you.
