# Quality bar — so we never get a refund or a bad review

## CV deliverable (every order)
- [ ] 2 pages max (1 page if under 3 years' experience)
- [ ] No photo, no date of birth, no marital status, no full address (town + county only) — Irish norm
- [ ] Profile paragraph: 3–4 lines, role-specific, no clichés ("hard-working team player" is banned)
- [ ] Each role: 3–6 bullets, each starting with a verb, at least half with a number or concrete result
- [ ] Education, then skills, then optional extras — reverse-chronological
- [ ] Standard font (Calibri/Arial 10.5–11), no tables, no columns, no graphics — ATS-safe
- [ ] Spellcheck with Irish/UK English (organise, programme, licence)
- [ ] Delivered as .docx AND .pdf
- [ ] Cover letter: 3 paragraphs, under 300 words, references the actual job ad, no generic filler
- [ ] Operator reads it start to finish once before sending. Anything that sounds like AI wrote it gets rewritten.
- [ ] Nothing invented: no fabricated achievements, dates, employers, or qualifications. If the buyer's CV is thin, we make it clear and honest, not padded.

## Grinds deliverable (every session)
- [ ] Prep pack sent to student 1 hour before
- [ ] Session runs to time; recap notes sent within 2 hours after
- [ ] Never claim a grade or credential you don't hold

## Response times
- Enquiry → reply: under 2 hours in daytime
- Payment → delivery: under 24 hours
- Revision request → done: same day

## Refund policy (stated up front)
Full refund if we miss the 24h deadline. No refund for "didn't get the job" — we never promised that.
